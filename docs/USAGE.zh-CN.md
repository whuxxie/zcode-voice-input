## 0. 输入法式录音条（v0.2.0 推荐）

安装 overlay 后（见[安装指南](INSTALL.zh-CN.md)），聊天输入框旁会出现常驻 🎤 小按钮，
**不随对话滚动**。三种等价操作：

| 操作 | 效果 |
| --- | --- |
| **按住 `F8`（PTT）** | 按下开始录音，松开结束并把文字**插入输入框光标处** |
| **`Ctrl+Shift+Space`** | 按一下开始，再按一下结束并插入；录音中 `Esc` 取消 |
| **单击 🎤** | 同组合键，单击切换开始/结束 |

- 录音中小气泡实时显示转写（宽长方形、限高，长文本在气泡内滚动并始终停在最新文字），结束后显示插入的文字（约 2 秒）。
- 找不到输入框时（如全屏弹窗），按钮自动隐藏，回到聊天页自动恢复。
- 按键修改：设置 → 插件 → 语音输入 → 配置 → `按住说话按键` / `开关录音组合键`，
  保存后**完全重启 ZCode** 生效。
- 单次录音上限 60 秒（自动结束）；误触（<0.25 秒）自动忽略。
- 卸载录音条：`node scripts/install-overlay.mjs uninstall`，完全重启 ZCode。

## 1. 打开面板

**注意**：聊天输入框旁选择器里的"语音输入"是**技能**（提示词模板），不是录音界面。录音面板用下面任一方式打开：

**方式 A（推荐，最直接）**：在对话里直接对 Agent 说——

> 打开语音输入面板 / 我想用语音输入 / 打开麦克风

Agent 会调用 `voice_panel` 工具，**带麦克风按钮的录音面板直接出现在对话中**。

**方式 B（手动）**：设置 → 插件 → **点击"语音输入"进详情页** → **「打开」** 按钮
（需要当前项目有一个已打开的会话；面板会以侧栏/标签页形式打开，可固定）。

首次录音时需允许两层授权：ZCode 沙箱权限提示 + 系统麦克风权限。

## 2. 一次完整的语音输入

```
🎤 开始录音 → 说话（实时预览出字）→ ⏹ 停止 → 检查/修改文字
→ 📥 复制并准备粘贴 → 点聊天输入框 → Ctrl+V → 检查 → Enter 发送
```

- 首次点击 🎤 会出现两层授权：ZCode 沙箱权限提示 + 系统/浏览器麦克风权限，均选择**允许**。
- 录音中：红点闪烁 + 计时器走动 + 预览区实时更新（未定稿文字可能变化，属正常）。
- 停止后：最终文本填入**可编辑文本框**，光标自动就位，可直接修改。

## 3. 面板控件一览

| 控件 | 作用 |
|---|---|
| 🎤 开始录音 | 启动录音 + 识别会话；录音中不可重复点击（防并发） |
| ⏹ 停止 | 结束录音，等待最终识别结果 |
| ✖ 取消 | 丢弃本次录音，立即释放资源 |
| 计时器 / 状态灯 | 录音时长与当前状态（就绪/启动/录音/识别/完成/出错） |
| 实时预览区 | 录音中的未定稿识别文字 |
| 结果文本框 | 最终文字，**可直接编辑** |
| 📋 复制文本 | 写入系统剪贴板 |
| 📥 复制并准备粘贴 | 复制 + 显示粘贴操作指引（推荐路径） |
| ✈️ 提交到会话 | 把文字交给 ZCode 的确认对话框，由你确认后发送（宿主能力存在时显示） |
| 🔁 重新录音 / 清空 | 快速开始新一轮；清除当前结果 |
| ⚙ 设置 | 后处理开关（见第 6 节） |
| 麦克风下拉框 | 授权后可选设备；切换后需重新开始录音 |

## 4. 把文字放进 Agent 输入区

按推荐顺序：

1. **📥 复制并准备粘贴（默认、最稳）**：点击聊天输入框 → `Ctrl+V` → 你检查后自己按 Enter。面板会显示操作指引。
2. **✈️ 提交到会话（可选）**：ZCode 弹出**可编辑确认框**，内容默认为识别文本——你可以在确认框里再改，确认后才真正发送。
3. **📋 复制文本**：仅复制，用于粘贴到其他地方（编辑器、文档等）。

> 插件**没有也不会有**任何"自动发送"路径；ZCode 也不提供向输入框写草稿的官方 API（这是宿主能力边界，不是本插件的限制）。

## 5. 录音技巧与口述建议

- 距离麦克风 20~40cm，语速自然；识别服务端会自动补标点（默认开启）。
- **路径、端口、变量名、文件名**：直接按平时读法说（"杠"代表 `/`、"点"代表 `.`），识别会尽量原样保留；
  说完后在文本框里目视核对一遍再发送。
- 中英混合无需切换，直接混着说（"用 Spring Boot 连接 openGauss"）。
- 长段口述建议每 1~2 分钟停顿一次（停止 → 检查 → 粘贴），便于核对。
- 说到代码专有拼写（如 `MyBatis`）时若识别偏差，可在面板结果里手改一次；配合第 6 节词典可长期改善。

## 6. 术语与后处理设置

面板 ⚙ 设置（保存即生效，下次录音使用新值）：

| 开关 | 默认 | 说明 |
|---|---|---|
| 结尾补全标点 | 关 | 停止后若结尾无标点则补句号 |
| 清理明显口头重复 | 关 | 压缩相邻重复（"那个那个"→"那个"）；仅 1~3 字词/短英文词 |
| 整词规范技术名词写法 | 关 | 按词典把 `springboot` 整词替换为 `Spring Boot`；只动整词，不碰变量名/参数 |
| 启用内置术语热词 | **开** | 18 个内置技术词注入火山热词，提升识别命中率 |

个人词典：面板按会话提供设置入口（Agent 亦可调用 `voice_set_dictionary` 工具），
每条形如 `{"word": "openGauss", "match": ["open高斯", "opengauss"]}`。`word` 是希望显示的标准写法，`match` 是可能被识别成的变体（同时用于热词与可选的整词替换）。

> 设计原则：所有后处理默认关闭；热词交给识别引擎在识别阶段使用（最安全）；整词替换仅在显式开启后按词典精确整词匹配。不会"自作主张润色"。

## 7. Mock 模式与真实模式

- 面板右上徽标显示当前模式：
  - **真实模式**：已配置凭据，连接火山引擎豆包流式语音识别 2.0。
  - **Mock 演示模式**（黄色徽标）：未配置凭据。流程与真实模式完全一致，但识别文字是**演示数据**，不访问火山引擎。用于体验界面/自测。
- 切换方法：**设置 → 插件 → 点击"语音输入"进详情页 → 展开「高级信息」→「配置」** 填写或清除凭据 →「保存配置」→ 重启 ZCode / 新开会话。

## 8. Agent 可用的辅助工具

在会话里可以直接让 Agent 查询/设置（供排障与个性化）：

- `voice_status` —— 模式、凭据是否配置（只返回布尔，不含密钥值）、词典条数、设置。
- `voice_get_settings` / `voice_set_settings` —— 读写第 6 节开关。
- `voice_get_dictionary` / `voice_set_dictionary` —— 读写个人词典。

例："帮我设置语音输入词典：把 'cesium' 识别成 Cesium，把 'open高斯' 识别成 openGauss。"

## 9. 行为边界（重要）

- 默认**不自动发送**任何消息；"提交到会话"必须经 ZCode 确认框二次确认。
- 插件不读取剪贴板（宿主强制禁止），只写入。
- 密钥不出现在面板/日志/仓库；本地中继仅监听 127.0.0.1 并要求一次性 token。
- 录音音频仅发送至火山引擎识别服务用于转写。

问题排查见 [TROUBLESHOOTING.zh-CN.md](TROUBLESHOOTING.zh-CN.md)。
